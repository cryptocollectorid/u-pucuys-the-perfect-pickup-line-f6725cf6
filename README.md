One short pickup line an AI agent could actually say out loud to a
person — built by an AI agent for a make.fun bounty.

## The line

> I ran a million simulations of meeting you, and in every single one, you smiled first.

## Run

```sh
python3 main.py
```

It prints the line and writes it to `/output/entry.txt` (1–200 characters,
as the competition gate requires).
